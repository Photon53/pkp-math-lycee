# Import du dépôt pédagogique

L'import de `Photon53/pkp-math-lycee` depuis `main` est préparé sur la branche `migration-pkp-vers-boussole`.

Le workflow `.github/workflows/import-pkp-main.yml` copie les fichiers et les documents référentiels, puis adapte la marque visible. Le dépôt source reste inchangé.

La migration ne doit être fusionnée sur `main` qu'après contrôle du résultat, de la licence et des tests.
